# ✊ Rock Paper Scissors Game ✋✌️

A fun and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**! Play against the computer and see who wins. 🎮

## 🎮 How to Play

1. Choose **Rock ✊**, **Paper ✋**, or **Scissors ✌️**.
2. The computer randomly makes its choice.
3. The winner is decided using these rules:

* ✊ **Rock beats Scissors ✌️**
* ✋ **Paper beats Rock ✊**
* ✌️ **Scissors beats Paper ✋**

## ✨ Features

* 🎲 Random computer choices
* 🧠 Automatic winner detection
* 📊 Score tracking
* 🔄 Play multiple rounds
* 🎨 Simple and responsive design
* 💻 Easy-to-use interface

## 🛠️ Built With

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Choose Rock, Paper, or Scissors.
5. Have fun! 🎉
